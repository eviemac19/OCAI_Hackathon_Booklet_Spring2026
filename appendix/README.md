# Appendix

Reference material for the booklet. Six files; the glossary is the one you'll come back to most often, the others are read-once.

| File | What it is |
| --- | --- |
| [`glossary.ipynb`](glossary.ipynb) | Clinical-AI glossary. Open it whenever a term comes up that you want to look up. Built around a single simulated cardiovascular-risk dataset so the terms don't feel abstract. |
| [`tech_stack.md`](tech_stack.md) | Every Python library the booklet uses, with pinned versions, links to the official docs, and which chapter introduces each. |
| [`further_reading.md`](further_reading.md) | Citations consolidated from across the booklet — datasets, methodological papers, governance frameworks, clinical guidelines. Grouped by section. |
| [`sponsors_and_credits.md`](sponsors_and_credits.md) | Sponsors, venue, mentors, coaches, and the post-event survey respondents who shaped this v1.0 edition. |
| [`changelog.md`](changelog.md) | Version history. Starts at v1.0; will track future revisions. |

If you spot an error or want to suggest an addition for the v1.1 edition, write to **events@clinicalaipartners.org**.
